# Решения задач курса «Поколение Python: курс для начинающих» на Stepik

В этом репозитории собраны мои решения практических задач по программированию в рамках обучающего курса от Stepik.org. 

### 📌 Особенности репозитория:
* Содержит решения большинства задач курса (пропущены самые базовые упражнения, не несущие практической ценности).
* Все решения успешно прошли автоматические тесты платформы Stepik.
* Код написан в учебных целях, поэтому не содержит сложных обработок ошибок («защиты от дураков») и не является коммерческим софтом.

### 🔢 Система нумерации файлов:
Все файлы с решениями пронумерованы по шаблону `X_Y_Z.py`, где:
1. **X** — номер урока.
2. **Y** — номер части внутри этого урока.
3. **Z** — порядковый номер конкретной задачи на программирование (теоретические вопросы и тесты в подсчете не учитывались).
