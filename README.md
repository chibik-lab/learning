обучение на курсе Stepik.org "Поколение Питон курс для начинающих"

Почти все решения для курса. Отсутсвуют самые простые и легкие задачки, которые не имеют никакой ценности. 
Задачи проверены тестами платформы, не содержат защиты от дураков и не являются "настоящими" программами.

задачи пронумерованы: 
1 цифра - номер урока
2 цифра - номер части в уроке
3 цифра - номер задания (в подсчете учитывались только задачи на програмирование, а не вопросы).
